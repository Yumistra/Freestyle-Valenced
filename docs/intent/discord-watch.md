# Discord Watch, Message Logger 연동 (확정된 의도)

- 결과: Message Logger 설정에 "알림 앱" 항목. "이 계정으로 켜기"(지금 로그인된 계정 토큰), "토큰 붙여 넣기"(다른 계정), 끄기, 지운 DM과 멘션 알림, 배터리 최적화 해제, 상태 보기를 모두 여기서 한다.
- 앱: 화면도 아이콘도 없다. 기록을 보낼 디스코드 패키지는 앱을 연 디스코드로 자동으로 정한다. 디스코드가 꺼져 있는 동안 지워지거나 고쳐진 메시지를 모아 두었다가 디스코드가 켜지면 로그로 넘긴다.
- 다른 계정을 감시할 때: 로그에는 들어가지만 채팅 안에 다시 넣지는 못하고 View logs 에서만 보인다.
- 성공 기준: 가짜 게이트웨이와 가짜 플러그인으로 전체 흐름이 통과하고, APK와 플러그인 zip 을 빌드해서 준다.
- 제약: 실제 기기 확인은 사용자가 한다. 레포에는 직접 푸시하지 못하니 바뀐 파일을 Termux 명령과 함께 zip 으로 준다.
- 하지 않는 것: 앱 안의 로그 화면, main 배포, 여러 계정 동시 감시.

## 추가 (2026-11-22 오후)

- 자동 수집: 디스코드를 켜거나 디스코드로 돌아오면 Discord Watch 가 모은 기록이 아무것도 누르지 않아도 들어와 View logs 에 나온다. 켜 둔 동안 새로 잡힌 것도 계속 들어온다.
- 설정 정리: 첫 화면은 저장 현황, View logs, 그룹 목록만. 그룹은 What to log, Who and where, In chat, Notifications, While Discord is closed, Storage 이고 눌러서 들어간다.
- 그대로: 알림, 기존 설정 값 (위치만 옮긴다).
- 하지 않는 것: 알림 바꾸기, 새 설정 항목, 앱 안의 로그 화면, main 배포.
